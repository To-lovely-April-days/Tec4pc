# TecStudio 新版本测试计划

## 界面导航（新版布局）

界面按使用频率分三层，找不到功能时对照这里：

| 位置 | 内容 |
|---|---|
| **顶栏**（深色） | 串口选择、连接/断开、开始/停止记录、设备型号、机内温度 |
| **左侧** | 温度曲线（含设定值虚线）+ 输出占空比曲线 |
| **右上 · 运行卡片**（常驻） | 状态徽标、TC1/TC2 大字读数、目标温度、**偏差**、**实时稳定度**、输出条、启停按钮 |
| **右下 · 工艺** 页 | 温度曲线（结晶）、串级控温 |
| **右下 · 整定** 页 | 自整定、PID 参数、积分预置、增益调度、手动输出 |
| **右下 · 设置** 页 | 反馈传感器、反向输出、硬件保护、波特率、控制周期、PWM 频率、通道同步 |
| **右下 · 监视** 页 | 两路温度/电流/电压、机内温度 |
| **状态栏** | 左：操作提示；右：周期耗时与占用率 |

> **实时稳定度**（运行卡片内）显示最近 5 分钟滚动窗口的 ±值、峰峰值与标准差，
> 验收时直接读数即可，无需事后用 Excel 处理 CSV。


本轮新增：积分预置与稳态前馈、增益调度、串级控温、温度曲线、PWM 频率设置、周期负载显示。
测试顺序按"**先回归、再新功能、最后出汇报数据**"排列，每轮独立，可分次进行。

已知基准（旧版实测，用于对比）：
- −10℃ 稳态：稳定度 ±0.06℃（峰峰 0.121℃），占空比 34.2%，电流 1.31/1.34 A
- 自整定 @−10℃：Ku=28.651，Tu=186.9s → 平稳型 Kp=12.893 / Ki=0.0314 / Kd=382.444
- 到温时间：19.5 分钟（16.3℃ → −10℃）

## 第 1 轮：回归测试（约 30 分钟，必做）

目的：确认新版本没有破坏已经能用的功能，并验证"启动加速"效果。

1. 编译新版本 → 运行 → 连接 COM6；
2. **检查界面**：工具栏出现"PWM频率"，状态栏右下出现"周期耗时 xx ms / 500 ms（占用 xx%）"；
   主面板出现"增益调度""串级控温""温度曲线"三个新区块；
3. **检查周期负载**：占用率应在 20~35%。若 >85% 说明串口吃紧，记下数值告诉开发；
4. 确认设置：反向输出 ✔、反馈传感器 = TC2 腔体、输出上限 90（RD105 固件占空比上限
   即 90%，不存在 100%）、
   Kp=12.893 / Ki=0.0314 / Kd=382.444 → 点"应用参数"；
5. 硬件保护确认：占空比上限 90（固件上限；新版"写入/读取"自动覆盖两个通道并核对
   一致性——两路输出镜像驱动，通道 2 限幅偏低会表现为其电流始终小一截）、
   限流 12A、过温 60 / −30 → 读取核对；
6. **积分预置**：勾选"积分预置%"，框内填 `34`；
7. 开始记录 → 目标 −10 → 启动控温。

**判据**：
- [ ] 头 1 分钟温度朝 −10℃ 方向走（不反向）；
- [ ] **到温时间明显短于 19.5 分钟**（预期 9~12 分钟）← 本轮核心指标；
- [ ] 超调 < 0.3℃；
- [ ] 稳态后面板灰字出现"已记录稳态输出 34.x%"与前馈工作点提示。

> 若到温时间没有改善，检查预置值符号：面板占空比显示为正时就填正数。

## 第 2 轮：串级控温验证（约 1 小时，重要）

目的：验证内部温度（TC1）能被控准——这是旧版做不到的（TC1 比 TC2 高 0.4~0.5℃）。

**前提：第 1 轮已稳定在 −10℃，且 TC1 已收敛（TC1 与 TC2 差值 5 分钟内变化 < 0.05℃）。**

1. 记录此刻的 TC1、TC2 数值（这是"单环"基准）；
2. 串级区：外环 Kp=1.5、Ki=0.0025、Kd=0、偏置±15 → 勾选"启用串级" → 点"应用串级设置"；
3. 观察 30~40 分钟。

**判据**：
- [ ] 面板出现"串级运行中：内部 x.xxx℃ → 腔体设定 x.xxx℃"；
- [ ] **腔体设定值被自动压低**（因为要让内部更冷），偏离量约 0.4~0.6℃；
- [ ] **TC1 内部最终稳定在 −10℃ ±0.1℃**；
- [ ] 无持续振荡（若 TC1 出现周期 >20 分钟的大幅摆动，说明外环偏快，把 Ki 减半重试）。

---

## 第 3 轮：温度曲线验证（约 1 小时）

目的：验证结晶降温曲线能被准确跟踪。

1. 保持控温运行（单环或串级均可）；
2. 曲线区选"分段曲线"，输入：`-20, 0.5, 20`（0.5℃/min 降到 −20℃ 后保温 20 分钟）；
3. 点"启动曲线"。

**判据**：
- [ ] 状态栏显示预计时长（约 20 分钟降温 + 20 分钟保温 = 40 分钟）；
- [ ] 曲线图上"主设定值"虚线呈匀速下降的直线；
- [ ] **实测温度紧贴设定值虚线，滞后 < 0.5℃**；
- [ ] 到达 −20℃ 后转入保温，进度走到 100% 后曲线自动结束、设定值保持 −20℃。

补充可选：阶梯降温测试，输入三行
```
-5, 2, 10
-15, 0.5, 15
-25, 0.2, 20
```

## 第 4 轮：增益调度建表（每点约 30 分钟）

目的：宽温域（0 ~ −40℃）自动适配参数。**只有当第 1 轮的参数在别的温度表现变差时才需要做。**

1. 先做**便宜的验证**：用现有参数分别在 **0℃** 和 **−25℃** 跑闭环各 20 分钟，看稳定度；
   - 两处都能进 ±0.1℃ → 增益变化不大，**一组参数够用，本轮可跳过**；
   - 某温区明显振荡或迟钝 → 在该温度做一次自整定，程序会自动登记进增益表；
2. 表中有 2 个点后，"增益调度"区会显示插值结果，例如
   `2 个温度点：0.0℃(Kp=10.20)，−25.0℃(Kp=18.40) · −13.0℃ 插值得 Kp=14.10 ...`；
3. 增益表自动存盘（`%AppData%\TecStudio\gain-schedule.csv`），重启后自动载入。

**判据**：
- [ ] 自整定完成后提示"已填入平稳型参数并登记到增益表"；
- [ ] 改变目标温度时，增益提示中的插值结果随之变化；
- [ ] 重启程序后增益表仍在。

---

## 第 5 轮：PWM 频率对比（约 40 分钟，可穿插）

目的：验证提高 PWM 频率能否改善低温可达能力（TEC 制冷量正比 I、焦耳热正比 I²）。

1. 停止控温 → 手动输出固定 **60%**；
2. FPWM 保持 **10Hz**，跑到平台（2 分钟变化 <0.1℃）→ 记录 TC2 最低温、两路电流；
3. 不停输出，FPWM 切到 **100Hz** → 点应用 → 再等 15 分钟；
4. 对比两个平台温度与电流。

**判据**：
- [ ] 100Hz 下平台温度更低（若低 1℃ 以上，则永久采用 100Hz）；
- [ ] 电流读数更平稳。

---

## 第 6 轮：长测（1~2 小时，出汇报数据）

目的：给出正式的稳定度结论。

1. 采用最终配置（建议：串级 + 积分预置 + 100Hz）；
2. 目标 −10℃，全程 CSV 记录 **至少 1 小时**（最好覆盖空调启停、人员进出等扰动）；
3. 用 Excel 取稳态段，计算 TC1 与 TC2 各自的峰峰值与标准差。

**判据**：
- [ ] TC2 峰峰值 ≤ 0.2℃（±0.1℃）；
- [ ] TC1 峰峰值 ≤ 0.2℃ 且均值与设定值偏差 < 0.1℃（串级生效）。
