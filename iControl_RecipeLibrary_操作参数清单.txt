1. 统一参数模型 (最重要的架构结论)
--------------------------------------------------------------------------------

iControl 的操作参数不是"每个操作一套独立表单"，而是一个统一的四段式结构，
不同设备只是暴露不同的枚举值：

    Operation
      |
      +-- Mode      控制对象 / 工作模式    (选哪个被控变量)
      +-- Task      任务类型                (怎么到达目标: 立即 / 按时长 / 按速率)
      +-- Control   数值参数                (目标值、时长、速率、曲线形状)
      +-- Advanced  该步执行期间的安全限值覆盖

建模建议：
  - 基类 OperationBase 承载通用属性 + Advanced 安全限值覆盖
  - Mode / Task 用两级枚举，Task 可用列表随 Mode 动态过滤
  - Control 段用参数字典或 discriminated union，避免为每个操作建独立实体


--------------------------------------------------------------------------------
2. 通用属性 (所有操作共有)
--------------------------------------------------------------------------------

  * Id                      [GUID, 系统生成]
  * DisplayText             [字符串, 自动生成, 只读]
        由参数自动拼装成人类可读描述
        例: "Heat/Cool Tr to 30 °C as fast as possible"
        例: "Ramp stirrer speed to 200 rpm over 10 sec"
        建议自研时同样做成计算属性，卡片上不显示原始参数

  * EstimatedStart          [时间跨度, 自动计算, 只读]           [确认]
        格式 HH:MM:SS，相对实验起点
        由前序操作时长累加得出，截图中每张卡片底部显示

  * PhaseId                 [引用, 可空]
        所属阶段分组

  * Alignment               [枚举: Series | Parallel]           [确认]
        与相邻操作串行或并行执行
        UI 表现: 并行操作卡片用虚线边框区分

  * Status                  [枚举, 运行时]                       [确认]
        Pending      白色
        InProgress   绿色
        Paused       黄色
        Aborted      红色
        Finished     灰色

  * AdvancedSafetyOverride  [对象, 可空]                         [确认]
        该操作执行期间临时覆盖的安全限值，字段同第 6 节
        注意：这是全局安全限值之外的一层 per-step 覆盖，
        自研系统如果只有全局限值，这一层必须补上

4. 操作清单 (按截图 Recipe Library 顺序)

=== 4.1 温控组 ===============================================================


[01] Distill                                                          [确认]
--------------------------------------------------------------------------------
说明 : Tj-Tr 模式的一种应用。用于沸点未知的溶剂或混合物蒸馏。
       控制逻辑 = 实测 Tr + 设定温差 → 得到 Tj 设定值。
       未沸腾时 Tr 按温差跟随上升；沸腾后 Tr/Tj 自然趋稳；
       Tj 触及 Tj end 后锁定该温度。

参数 :
  * Tj-Tr                   [数值, °C, 必填]
        期望的夹套-物料温差
  * Tj end                  [数值, °C, 必填]
        夹套温度上限，到达后保持

约束 :
  - 需要 Tr 传感器已连接且未被禁用
  - 固件层强制限制 Tj-Tr 最大 60 K (防玻璃反应器热应力破裂)


[02] Heat/Cool                                                        [确认]
--------------------------------------------------------------------------------
说明 : 核心温控操作，参数最完整，是统一参数模型的样板

参数 :
  * Mode (Select mode)      [枚举, 必填]
        Tr      控制物料温度。反应放热造成的 Tr 偏差由夹套温度自动修正
        Tj      控制夹套温度，恒值或斜坡
        Tr-Tj   蒸馏 / 结晶模式

  * Task (Select task)      [枚举, 必填]
        As fast as possible     全功率趋近目标
        Ramp by duration        按时长升降温
        Ramp by rate            按速率升降温

  * End value               [数值, °C, 必填]
        目标温度

  * Duration                [时长]  Task = Ramp by duration 时必填
  * Rate                    [数值, °C/min]  Task = Ramp by rate 时必填

  * Ramp shape / Exponent   [数值, 可选]
        线性斜坡带指数参数，可生成非线性升温曲线
        对话框内有曲线形状预览图
        ★ 易漏点: iControl 不只支持直线斜坡

  * Advanced options        [对象, 可选]
        该操作期间的安全限值覆盖

温度范围 (EasyMax 102/402):
  Tj : -40 °C (需 Tc < -15 °C) ~ 180 °C，分辨率 0.1 K
  Tr : -40 °C (需 Tc < -15 °C) ~ 180 °C，分辨率 0.1 K
       实际可达上下限取决于夹套传热能力和反应放热量
  数据采集与设定值计算周期: 2 秒


[03] Reflux                                                           [确认]
--------------------------------------------------------------------------------
说明 : 与 Distill 共用 Tj-Tr 模式和同一套控制逻辑，参数结构相同，
       语义上区分为回流而非蒸馏

参数 :
  * Tj-Tr                   [数值, °C, 必填]
  * Tj end                  [数值, °C, 必填]

约束 : 同 Distill


=== 4.2 搅拌组 ===============================================================


[04] Stir                                                             [确认]
--------------------------------------------------------------------------------
参数 :
  * R end                   [数值, rpm, 必填]
        目标转速，范围 50 ~ 1000 rpm
  * Task                    [枚举]
        Immediate               立即生效
        Ramp by duration        转速斜坡
  * Duration                [时长]  Task = Ramp 时必填
  * Stirrer type            [枚举: Overhead | Magnetic]
        仅当顶置搅拌器已连接时才允许切换

约束 :
  - 不得超过 Rmax 安全限值
  - 使用玻璃桨或金属锚式桨时 Rmax 必须降至 500 rpm
  - 顶置搅拌最大连续扭矩 59 mNm
  - 数据记录周期 2 秒

  * Rate                    [数值, mL/min 或 g/min, 必填]
  * Total amount            [数值]  与 Duration 二选一
  * Duration                [时长]  与 Total amount 二选一
  * End condition           [枚举]  达量停 / 到时停 / 手动停

=== 4.4 采样组 ===============================================================


[08] Take Sample                                                      [确认]
--------------------------------------------------------------------------------
说明 : 两种模式，取决于是否接了 EasySampler

模式 A - 手动采样记录 :

模式 B - EasySampler 1210 自动采样 :

5. 温度控制模式详解
--------------------------------------------------------------------------------

Tr 模式                                                               [确认]
  控制反应物料温度。Tr 恒定或按斜坡变化。
  反应放热造成的 Tr 偏离由夹套温度自动修正，即产生的热量被导出。

Tj 模式                                                               [确认]
  控制恒温器 (夹套) 温度。Tj 保持恒值或按斜坡变化。

Distill / Reflux 模式 (Tj-Tr)                                         [确认]
  适用于沸点未知的溶剂或混合物。
  设定值计算: Tj_setpoint = Tr_measured + (Tj-Tr)
  行为: 溶剂未沸腾时 Tr 按设定温差上升;
        混合物沸腾后 Tr 与 Tj 均近似恒定;
        Tj 到达 Tj end 后保持该终值。
  必填两个参数: 温差 Tj-Tr、夹套上限 Tj end

传感器 :
  Tr  测反应器内容物温度 (Pt100)
  Tj  测反应器夹套温度
  Tc  测冷却元件温度

6. 安全限值参数完整表 (EasyMax 102 / 402)                             [确认]
--------------------------------------------------------------------------------

参数        含义                                    取值范围
---------   -------------------------------------   -------------------------
Tsafe       触发 E 级紧急程序后降至的安全温度        按化学体系确定
Tr max      Tr 上限，超过触发 E 级紧急程序           Tsafe + 3K ~ 183 °C
Tr min      Tr 下限，低于触发 E 级紧急程序           -43 °C ~ Tsafe - 3K
Tj max      Tj 上限，超过触发 E 级紧急程序           Tsafe + 3K ~ 183 °C
Tj min      Tj 下限，低于触发 E 级紧急程序           -43 °C ~ Tsafe - 3K
T diff max  允许的 Tj 与 Tr 温差                     随反应器类型变化
Rsafe       紧急情况下的搅拌转速                     Hold (保持) 或 0~1000 rpm
Rmax        搅拌转速上限                             ≤1000 rpm
                                                     玻璃/金属锚式桨须降至 500

其他安全机制 :
  - Tr 模式与蒸馏/回流模式下，固件强制限制 Tj-Tr ≤ 60 K，防止玻璃破裂
  - 蒸馏/回流模式下 Tj 设定值被限制在 Tj end 以内
  - 所有输入值做合理性校验，防止误输入导致严重后果
  - 微处理器看门狗、搅拌电机监控、开机自检

7. 紧急程序分级 (对报警设计有直接参考价值)                            [确认]
--------------------------------------------------------------------------------

★ 这个二分法比单纯按颜色分级更有工程意义，可直接映射到 ISA-101 报警的
  可确认性 (acknowledgeable) 设计。

紧急程序 A —— 不可复位
  性质 : 多为硬件故障，必须断电排障
  触发 : 通讯中断 / A-D 转换器故障 / Power PIC 错误 /
         Tj 传感器故障 / Tc 传感器故障 / Tc 超过 Tc max
  处理 : 关机重启或呼叫服务，无法在软件层 Reset 后继续
  例外 : "Tc 高于 Tc max" 在 Tc 回落后可 Reset 并继续中断的实验

紧急程序 E —— 可复位
  性质 : 多为应用层故障，排除后可继续实验
  触发 : Tr 传感器故障或未连接 / Tr > Tr max / Tr < Tr min /
         Tj > Tj max / Tj < Tj min
  处理 : 点击 Reset → 等待测量值回到限值内 → 继续实验
  联动 : 触发后系统按 Tsafe 降温，搅拌按 Rsafe 执行

  6. Operator Message —— 是否支持多按钮分支
  7. HFCal U and cpr determination —— 标定时序的完整参数
