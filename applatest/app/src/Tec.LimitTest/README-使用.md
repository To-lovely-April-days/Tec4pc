# 控温极限测试工具（Tec.LimitTest）

给现场做极限测试用的独立小程序：按「最低温 / 最高温 / 恒温稳定性 × 冷却水 20 / 15 / 7 ℃」的
矩阵自动跑，数据直接写进「控温极限测试记录」工作簿（9 张表 + 结果汇总矩阵），不用人抄。
界面从简，主要是把数据填对。

## 跑之前

- **串口只能一个程序占着。** 把工作站（Tec.App）和设备 HMI 关掉再开这个工具；测完再开回去。
- 台面：工具自己的数据目录是 `%AppData%\TecLimitTest\`，里面的 `bench.json` 就是台面（格式跟工作站的
  台面文件一样）。第一次开机没有的话，先从设备 HMI 的 `%AppData%\TecHmi\bench.json` 拷一份；那也没有就写一份
  缺省的（主机 + 两支宇电探头，串口按驱动缺省 COM7 / COM10 / COM8）。串口不对在左栏改，点「保存并连接」。
  也可以「导入台面…」选工作站另存的 `.tecbench` 或实验文件 `.tec`。
- 运行：`dotnet run --project src/Tec.LimitTest`，或发布后双击 `Tec.LimitTest.exe`。
  数据目录可用环境变量 `TEC_LIMIT_DATA` 改。

## 界面怎么用

1. 左栏填串口，点「保存并连接」。顶上写「已连接：双工位反应主机（R1）· CH1 / CH2」才算连上；
   哪台设备没开起来，它下面的状态会写原因。
2. 填测试条件：操作人、环境温度（手填）、补丁版本、输出目录（缺省 我的文档\控温极限测试）。
3. 参数缺省 −40 / 150 / 25 ℃，60 / 60 / 120 min，都可以改。目标超出温控器超温上下限会拒绝开始。
4. 矩阵里勾要跑的格。同一个水温下按「最低温 → 最高温 → 恒温」串着跑，两项之间先回到 25 ℃ 附近。
5. 点「开始」。工具停在「请把冷却水调到 20 ℃…」：把冷水机调好、等水稳，把冷水机上看到的实际水温填进去，点「继续」。
   这一组不做就点「跳过当前」。每换一个水温都会停下来问一次。
6. 中途：「跳过当前」跳过正在跑的那一格；「停止」结束整轮（当前那格记中止）；「急停」设备所有输出收安全态。

## 每一项怎么跑

| 项 | 做法 | 什么时候结束 |
|---|---|---|
| 最低温 | 两工位同时「尽快」下发夹套目标（缺省 −40 ℃） | 跑满时长；或最近 10 min 两工位夹套变化都不到 0.2 ℃（提前结束，可关） |
| 最高温 | 同上，目标缺省 150 ℃；「切到电加热的时刻」从热源状态量的跳变记 | 同上 |
| 恒温稳定性 | 下发目标（缺省 25 ℃），等两工位都进 ±0.5 ℃（到达用时进表），再记录 2 h | 记录满时长；90 min 没到目标算中止 |

中止的情况：操作人停止 / 跳过 / 急停；安全层触发（Tr 越限、设备告警字、信号丢失）；两工位夹套连着 30 s 没读数；
夹套跑出设备范围 2 ℃ 以外。原因写进那张表的「结果」格，之前写的行都在。

## 数据从哪来、哪些是手填的

- 夹套温度 / 输出 / 热源 / TEC 功率线：驱动每秒采样，取记录点那一刻的值（最低温 / 最高温每 1 min 一行，恒温每 2 min）。
- 釜内温度：宇电探头会话发的 Tr；没接探头这一列就是空的。
- 电流：温控器「实时状态」里的 CURRENT，每 5 s 读一次。
- LIMITED、超温上限：开始每一格时从温控器读；电加热切换阈值、热源死区：从台面配置读。
- **手填的只有三样**：操作人、环境温度、冷却水温度（不是测的，工具问你，你填冷水机上看到的数）。
- 没采到的格子留空，工具不编数。每秒的全量数据在输出目录的 `csv\` 里，一次测试一个文件。
- 记录表每到一个记录点保存一次；`结果汇总` 那张全是公式，Excel 打开时算。
