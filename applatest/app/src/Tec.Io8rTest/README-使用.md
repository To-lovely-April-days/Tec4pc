# IO8R 继电器测试 · 使用说明

只连 IO8R、手动一路一路合 / 断继电器的小程序。**温控器（RD105）不碰**——TEC 由别的电脑控制、
这台只管通断（比如单独给通道 1 合制冷做测试）时用它。

## 用法

1. **先把占着 IO8R 的程序断开**：HMI / 工作站 / 极限测试工具连着这台双工位主机时，在那边断开设备或关掉程序。
   串口只能一个程序占着，不然这里报「串口被占用」。
2. 双击 `Tec.Io8rTest.exe`，串口 / 波特率 / 站号按 IO8R 填（现场缺省 COM10 / 9600 / 1，窗口下面列着本机有的串口），点「连接」。
   连上先读回八路当前位置，不先全断。
3. 每一路一行，点「合上」/「断开」切那一路；只写那一路，别的不动。状态列是**读回**的位置，每秒刷一次，模块面板上人手扳了也照实变。

| DO | 接的是 |
|---|---|
| DO0 / DO1 | 通道 1 / 2 加热棒 |
| DO2 / DO3 | 通道 1 / 2 使能 |
| DO4 | 冷却水阀（占的是「通道 1 辅助加热」那一路） |
| DO5 | 没接（「通道 2 辅助加热」那一路） |
| DO6 | 通道 2 制冷（TEC 功率线） |
| DO7 | 通道 1 制冷（TEC 功率线） |

## 保护

- **同一通道的加热棒和制冷不能同时合**（通道 1：DO0 ⇄ DO7，通道 2：DO1 ⇄ DO6）：另一只合着就拒绝，日志里说先断哪只。
- **制冷合着而冷却水阀没开**：窗口里黄条提醒（TEC 没水会干烧），不拦。冷水机本程序不管，在冷水机面板上开。
- **断开 / 关程序时八路全断。**
- 「八路全断」按钮随时一键全断。

## 出包

`scripts/publish-io8r-test.cmd`（Windows）或 `scripts/publish-io8r-test.sh [RID]`，产物在 `dist/tec-io8r-test-<RID>/`，
单文件 exe，拷整个目录到目标电脑就能跑，不用装 .NET。
