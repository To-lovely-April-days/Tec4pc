# 开发环境备忘

程序本身不依赖这些，**跑起来、编译、测试都不需要**。这里记的是「在 Linux 上
截图比对样式」时才要的那点布置——不写下来，下次截出来的图又会带着同样的失真。

## 字体：截图里的中文字重会骗人

程序声明的字体栈是按目标机器（Windows）写的：

```
Segoe UI, Microsoft YaHei UI, Microsoft YaHei, system-ui, Arial
```

这三样 Linux 上一个都没有。**要命的不是长相不同，是字重会塌**：
容器自带的中文字体（WenQuanYi Zen Hei、Droid Sans Fallback）只有 Regular 一档，
`FontWeight="Light"` 无处可落，于是所有中文都按 Regular 画出来，
比 Windows 上（微软雅黑 UI 有 Light 档）粗一截。照着这样的截图去调字重、
调字号，调出来的值到了现场全是错的。

装一套有全字重的中文字体，再把雅黑别名到它：

```bash
apt-get install -y fonts-noto-cjk fonts-noto-cjk-extra fonts-noto-core
# fonts-noto-cjk-extra 才带 Thin/Light/DemiLight/Medium/Black，
# 只装 fonts-noto-cjk 的话仍旧只有 Regular 和 Bold
```

`/etc/fonts/local.conf`：

```xml
<?xml version="1.0"?>
<!DOCTYPE fontconfig SYSTEM "urn:fontconfig:fonts.dtd">
<fontconfig>
  <alias binding="strong">
    <family>Microsoft YaHei UI</family>
    <prefer><family>Noto Sans CJK SC</family></prefer>
  </alias>
  <alias binding="strong">
    <family>Microsoft YaHei</family>
    <prefer><family>Noto Sans CJK SC</family></prefer>
  </alias>
  <alias binding="strong">
    <family>Segoe UI</family>
    <prefer><family>Noto Sans</family><family>DejaVu Sans</family></prefer>
  </alias>
</fontconfig>
```

验一下确实拿得到 Light（不是退回 Regular）：

```bash
fc-cache -f
fc-match "Microsoft YaHei UI:weight=light"   # 要出 NotoSansCJK-Light.ttc
```

再验程序真吃到了：截一张图，量同一块区域的深色像素占比（墨量），
跟浏览器里同字体 300 / 400 两档比——落在 300 那边才算对。

```bash
convert 截图.png -crop 700x34+10+8 +repage -colorspace Gray \
        -threshold 65% -negate -format "%[fx:mean*100]\n" info:
```

实测：weight 300 → 10.8 %，weight 400 → 16.6 %，程序 → 11.6 %。

## 截图：Xvfb + openbox

```bash
Xvfb :99 -screen 0 1600x1000x24 &
DISPLAY=:99 openbox &
DISPLAY=:99 dotnet src/Tec.App/bin/Debug/net8.0/Tec.App.dll &
DISPLAY=:99 import -window root shot.png
```

**别用 `pkill -f "Tec.App.dll"` 收尾**：那串模式自己也在发起命令的 shell 的
命令行里，pkill 会把这层 shell 一起杀掉（表现是命令莫名其妙退出、日志文件
根本没建出来）。把重启写成一个脚本文件再 `bash 脚本` 跑，模式就不在命令行上了。

## 拿原型 HTML 做 1:1 比对

原型件用同一台机器的 Chromium 无头渲染，尺寸跟程序窗口一致，
再把两张图叠起来量——比拿眼睛估准得多：

```bash
/opt/pw-browsers/chromium --headless --disable-gpu --no-sandbox --hide-scrollbars \
  --window-size=1600,1000 --screenshot=ref.png "file:///path/原型.html"
```

量墨迹外框（去掉抗锯齿的灰边）：

```bash
convert ref.png -crop 700x46+0+36 +repage -colorspace Gray \
        -threshold 60% -negate -trim info:
```

一条量出来的经验：**同样 25px，拉丁大写实高 18px，中文实高 24px**——
汉字占满字身框，拉丁大写只占约 0.72。照抄原型字号，中文会大三分之一。
