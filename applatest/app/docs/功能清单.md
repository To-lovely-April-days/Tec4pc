# TecStudio 功能清单

做完一项就把 `[ ]` 改成 `[x]`，并在行尾补一句「谁做的 / 哪个 patch」。
这份清单是我们唯一的进度表——界面对不对照原型看 `tecstudio.html`，
功能做没做看这里。

图例：`[x]` 已完成并验证过 · `[ ]` 未做或只有壳子 · **粗体** 是当前建议优先做的。

一条铁规矩：**界面上出现的每一个数都得有出处。**没有出处就显示空状态，
把「还没有」写清楚，绝不摆演示数据糊过去。

## 建议顺序

1. ~~存盘 / 读取（台面 + 配方 + 配方库）~~ —— 已完成
2. ~~手动控制面板~~ —— 方案已定（弹设备自带屏幕），**等界面稿**，先跳过

   `TecControl.Core` 已经把协议和 PID 都封好了，而且 `ISerialTransport`
   是接口——没有硬件也能拿假串口跑通、写回归测试

7. 导出的报告模板与签名
8. 化合物「提取到配方参数」、新增 / 导入
