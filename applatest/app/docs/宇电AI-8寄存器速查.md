# 宇电 AI-8 系列多路模块 · 寄存器与输入规格速查

来源：用户提供的《AI-8 系列高精度多路 PID 调节器使用说明书》（8x8 / 8x6 / 8xx8 / 8x8G / 8x6G，51 页）。
下面只抄本项目用到的部分，页码按 PDF 页。**现场那台是 AI-8848G D91 J7 G71 N G61 S2 -24VDC**——
说明书 §1.1（p.5）拿它当例子：J7 = 热电偶 / 热电阻通用输入（固化，非模块化），S2 = 固化 485，Modbus-RTU。

代码：`src/Tec.Drivers.DualStation/Yudian/YudianClient.cs`。

## 通讯（§7，p.42~49）

- Modbus-RTU，支持 03H 读、06H 写单个、10H 写多个；8N1；波特率 4800~115200。
- 出厂默认地址 1、波特率 19.2K（p.22）。Addr 在 0840H（2112），bAud 在 0841H（2113，单位 0.1K）。
- 每条指令仪表在 0~5 ms 内应答；上位机要等应答回来再发下一条（p.49）。
- 参数写入次数没有限制，内部存储器不会因频繁写入损坏；只受 Loc 约束（p.4）。
- 对 0800H~088FH 之间的参数，写超范围的值会被仪表自己钳到范围内（p.49）。

## 寄存器（地址十进制 = 代码里用的）

| 代号 | 十进制 | 参数 | 说明 |
|---|---|---|---|
| 0180H~ | 384~ | In01~In96 | 输入通道配置。**个位 1~4 = 用第几组输入参数，0 = 关闭该通道**；十百位 = 多段曲线修正入口（0 不修正）。例 In01=112：通道 1 用第 2 组，修正入口 d11（p.23） |
| 0600H~ | 1536~ | PV1~96 | 测量值，只读，有符号 16 位（p.44） |
| 0660H~ | 1632~ | PV1~8 32bit | 高分辨率 32 位测量值，仅正数（没用） |
| 0680H~ | 1664~ | 报警状态 | 一个寄存器两路：**高字节奇数通道、低字节偶数通道**；bit0/8 输入错误或超量程（oral），bit1/9 HA，bit2/10 LA，bit3/11 dHA，bit4/12 dLA（p.44） |
| 0800H~0803H | 2048~2051 | InP1~4 | 输入规格（表见下） |
| 0804H~0807H | 2052~2055 | ScL1~4 | 线性输入刻度下限，单位同测量值 |
| 0808H~080BH | 2056~2059 | ScH1~4 | 线性输入刻度上限 |
| 080CH~080FH | 2060~2063 | FIL1~4 | 数字滤波 |
| 0850H | 2128 | dPt | 面板小数点位置，**不影响上位机读到的数**（p.33） |
| 0852H | 2130 | Loc | 参数锁：Loc.5=1 不允许写 0800H~08FFH；Loc.6=1 不允许单字节写；Loc.7=1 不允许多字节写（p.33） |
| 0853H | 2131 | 型号特征字 | 只读，表示仪表型号。现场读到 8848（0x2290）（p.47） |

## 现场那台读回来的样子（2026-09-21）

- 型号字 8848，In 四路全开（1/2/3/4），**InP 四路全是 51（4~20mA）**——可这台是 J7 热阻口，
  说明书标注 50/51 是 J4 电流模块专用：出厂参数配错了，Pt100 接上去一路都读不了。
- 处置：Tr 探头配置「输入规格」选「写成 Pt100（InP=21）」、「宇电通道」手选那一路再点「连接」，
  程序用 06H 写 InP 后重读核对（`YudianProbeSession.WriteInpAsync`）。模块没有面板，改参数只能走总线。
