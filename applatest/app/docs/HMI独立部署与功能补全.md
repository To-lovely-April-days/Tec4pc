# HMI 独立部署与功能补全（定稿方案）

用户定的三件事：①手动控制面板的功能按真机能力**全部做实**；②**蒸回流**
（TrTj：夹套跟着釜内走，Tj 目标 = Tr + ΔT）真正实现；③HMI 拆成**独立项目**，
打包后直接装到设备上当触屏 HMI 用。铁规矩照旧：每个数有出处、灰格子点了
说人话、不伪造成功。

勘察结论（四路并查，2026-09）：面板现有控件几乎没有假的——绝大多数已接真
能力/真数据，剩下的全是「诚实禁用」；但有两个**要命的地基缺口**先补：

- **缺口一：真机会话解析不了任何温度指令。** 控温/梯度/恒温/自然冷却的执行
  器（只按 ABI 能力写的）住在仿真器程序集里、只被仿真会话注册；纯真机台面
  跑含温度步的配方会报「该通道没有能执行此指令的设备」。
- **缺口二：真机上任何面板序列都启动不了。** 序列翻译器给每个非 R 步都可能
  插隐形的搅拌换挡步（起点 0 rpm、卡片缺省 200 rpm），真机没有 IStirrer，
  校验器直接拦，而报错步号还是翻译件的、对不上操作人自己那 6 张卡。

## 分步实施（每步一个补丁）

**A. 地基**
1. ✅（0278）温度指令执行器搬家：四个执行器 + 时间助手从仿真器搬到 Tec.Driver.Abi
   （指令语义的参考实现跟指令声明住一起），仿真会话与真机会话（DuoSession/
   Rd105Session）同一套认领——「仿真调好的配方插上真机能跑」从此对温度步成立。
2. ✅（0279）搅拌/加料诚实化：加 HasStir，照加料徽章的式样收口——无搅拌时徽章显示
   「— / 未接搅拌」（不再显示像实测的 0）、搅拌卡副标题不再写死仿真器规格、
   转速/斜坡输入禁用、Commit 不再对没搅拌的机器报「已写入控制器」；序列页
   R 格按能力禁用（文案：这台主机没有搅拌接口——搅拌协议未知）；**翻译器在
   无 IStirrer 时跳过隐形换挡插步**，纯温控序列真机可跑；启动被拦时用面板卡
   序号报人话。搅拌协议拿到后按能力接口接入，这些禁用自动解开。

**B. 蒸回流（TrTj）全链**
3. ✅（0280）ABI + 指令：新可选能力接口（夹套跟随：ΔT、Tj 上限、启停），HMI 的 TrTj
   格子按 Has<T>() 亮灯；CommandSpecs 加蒸回流指令（ΔT / Tj 上限 / 时长，
   Timer 结束——回流时 Tr 停在沸点，「到达判据」无意义）；校验器加
   「步骤 ΔT 与在册 T diff max 冲突」交叉检查；老配方 tec.temp.reflux 补迁移。
4. ✅（0281）仿真器：热模型改双状态（Tj 为被控量、Tr 经夹套换热跟随 Tj，顺带修好
   「夹套控温」名不副实的老账），加可设沸点让 Tr 出平台；跟随 Tick 带限速与
   Tj 上限钳制；RefluxHandler 注册。
5. ✅（0282）真机：跟随环挂在 DuoSession 采集循环里（每拍 Tj_set = Tr + ΔT，写 TG 用
   SPEED 限速不阶跃）。四条互锁：Tr 无效（探头断线）立即停跟随不拿残值抬
   夹套；Tj_set 越过电加热阈值走全套热源切换序列；SafeStop / E 级程序 /
   StopHeating 之后跟随环必须已被压制（门闩），绝不下一拍把 TG 写回去；
   Tj 上限之外还有设备超温保护寄存器兜底。
6. ✅（0283）HMI：TrTj 格子/模式按钮按能力解灰，ΔT 输入进键盘，TranslateSeq 加分支，
   控制页第三模式下发。

**C. HMI 独立项目（设备端部署）**
7. ✅（0284）抽共享：App.axaml 里 HMI 用到的资源/样式（UiFont/Shell/滚动条/输入框）抽成
   Theme.axaml；HmiView/HmiViewModel/六个自绘控件/15 个 hmi-*.svg/ViewModelBase
   搬进新类库 **Tec.Hmi.Ui**；avares 程序集名跟着改；ExperimentStore.DataDir
   改注入路径；对仿真 StirrerImpl 的具体类型特判上提成 ABI 可选能力。
   工作站（Tec.App）改引该库，HmiWindow 弹窗壳留在工作站，行为零变化。
8. 精简工作台 **Tec.Hmi.Runtime**：只带八件套（时钟/目录/驱动注册/管道/仲裁/
   执行引擎/安全监控/归档）+ 真机三驱动注册 + 固定台面（一台双工位主机 +
   两支宇电探头，连接参数从设备上的一份 JSON 配置文件读）+ 跨会话 Tr 喂数 +
   1s 安全定时器 + 30s 归档快照。不带登录/台面页/配方库/化合物库/SQLite。
9. 设备端可执行 **Tec.Hmi**：极薄 App（FluentTheme + Theme.axaml + 内嵌中文
   字体——设备可能不是 Windows，雅黑不存在，必须内嵌并配字体回退）+ 全屏
   无边框窗直接承载 HmiView（不用 1282×752 的桌面弹窗壳，1280×720 物理屏
   放不下它）。发布：`dotnet publish -r <rid> --self-contained
   /p:PublishSingleFile=true`，**绝不 PublishTrimmed**（反射绑定 + 运行时驱动
   加载都不兼容）；System.IO.Ports 按 RID 发布，Linux 上运行账号要进 dialout
   组；drivers/ 与 Resources/ 随包散装。附部署 README。
10. 联调：Xvfb 全流程截图 + 全量回归。

## 如实保留的禁用（协议/硬件到位前不假装）

- 搅拌：通讯协议未知——控制页/序列页全部按能力禁用，文案写明原因。
- 加料：这一路没接泵——现状已诚实，保持。
- pH 反馈加料：闭环实现在加料泵那边，接真泵再通。
